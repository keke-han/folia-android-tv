# Folia TV · 安卓电视遥控器优化版

**非原创、非官方二次开发项目。** 本项目基于 [whycfawa/folia-android](https://github.com/whycfawa/folia-android) 的 Android 移植版，继续针对 **Android TV / 安卓电视盒子和遥控器** 优化；原始 Folia 来自 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major)。感谢两级上游作者及所有贡献者。

原项目提供以桌面和 Web 为主的音乐与歌词体验；Android 移植版提供安卓容器与平台桥接。本分支重点解决大屏电视上焦点难找、设置选不到、键盘误弹出和播放操作不顺手的问题。它不是三星 Tizen 原生应用，三星遥控器通过盒子或 HDMI-CEC 使用时，以安卓设备实际收到的按键为准。

当前开发版本 **1.0.5** · Android **7.0+（API 24）** · 独立包名 `top.izuna.foliamajor.tv` · 桌面名称 **Folia TV**。

## 遥控器怎么用

| 场景 | 按键 | 操作 |
|---|---|---|
| 播放主画面 | 左 / 右 | 上一首 / 下一首；长按一次只切一首 |
| 播放主画面 | 中间确认键 | 暂停 / 继续播放 |
| 播放主画面 | 上 / 下 | 唤出播放控制栏，默认选中暂停按钮 |
| 播放控制栏 | 下 | 从按钮进入进度条；再次向下回到主画面 |
| 进度条已选中 | 左 / 右 | 后退 / 前进 5 秒，此时不切歌 |
| 浏览、歌曲列表、设置 | 长按下键约 1 秒 | 返回正在播放页，保留歌曲、进度和暂停状态 |
| 普通页面 | 上下左右 / 确认 | 移动焦点 / 打开选项；左右键不会切歌 |
| 设置侧栏 | 上下 / 右或确认 | 选择分类 / 进入参数；左边界返回分类 |
| 设置侧栏 | 左 | 进入底部“正在播放”；上键可回到之前控件 |
| 搜索与文字框 | 确认 / 返回 | 开始输入并弹键盘 / 结束编辑，经过输入框不会弹键盘 |
| 歌单 / 曲库 | 确认 / 返回 | 打开当前放大卡片或播放歌曲 / 回到上一页 |
| 任意普通页面 | 返回 | 返回上一层；在首页退出应用 |

长按下键在文字编辑、展开的下拉框及阻塞式弹窗中让位于当前操作。需要先结束编辑或关闭弹窗。底部“正在播放”入口仍然保留；只打开播放页，不会重新从头播放。

播放页的按钮和进度条闲置约 **3 秒淡出**，暂停时也会淡出；按上或下重新显示。退出到桌面或切换应用会暂停并保存位置，重新进入保持暂停，按确认继续。强制断电等异常中断可能只能恢复到最近一次成功保存的位置。

## 电视版做了什么

- 设置和歌词样式分类改为左侧列表，方向键可以到达各项，参数随焦点滚动。
- 保留动画与背景的效果缩略图和实时预览，不把原有效果功能删掉。
- 使用明显的黄色焦点框；歌曲网格只突出当前卡片，避免整块画布多余白框。
- 曲库与歌单进入时优先聚焦中间放大的卡片，返回键直接返回。
- 支持确认键播放暂停、主画面左右切歌和长按下返回正在播放。
- 电视版默认仅显示主画面原文歌词，关闭下方重复的歌词预览/翻译黑框；英文歌词仍显示英文。
- 遥控器按键立即响应并限制重复频率；实际流畅度取决于电视性能、WebView 和所选动画。

## 安装与更新

本仓库的 APK 以 [Releases](https://github.com/keke-han/folia-android-tv/releases) 中明确标注的附件为准；源码仓库不存放安装包。请勿从上游电脑版下载链接寻找 TV APK。

下载 APK 后，通过 U 盘或电视支持的安装方式侧载，并仅为本次安装授权可信来源。电视版独立安装，不覆盖原 Android 版；首次使用需要重新登录或导入设置。在线音源需要网络，音乐服务是否可用受地区、账户和平台接口变化影响。

当前本地测试 APK 使用调试签名。覆盖更新必须同时满足 **同包名、同签名且 versionCode 递增**；其他开发者或 CI 生成的调试 APK 通常无法直接覆盖此包。不要卸载来解决签名冲突而未先备份设置。公开正式签名安排见 [构建与发布](docs/TV_RELEASE.md)。

## 从源码构建

需要 Node.js 24+、JDK 21、Android SDK Platform 36.1，以及 Android 工程要求的 Build Tools。先配置 `JAVA_HOME` 和 `ANDROID_HOME`；不要把本机路径或签名凭据提交仓库。

```sh
npm ci
npm run build:android:tv
```

输出：`android/app/build/outputs/apk/debug/app-debug.apk`。更多调试、验证及 Windows 命令见 [ANDROID_TV.md](ANDROID_TV.md)。
